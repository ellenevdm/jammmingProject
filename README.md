# Jammming

Jammming is a React-based web application that allows users to search for songs via the Spotify API, create custom playlists, and save them directly to their Spotify accounts.

## Key Features

- Search for tracks using the Spotify API
- Add or remove tracks from a custom playlist
- Save playlists directly to your Spotify account
- Responsive and intuitive user interface built with React

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ellenevdm/jammmingProject
   ```
2. Navigate to the project directory
   ```bash
   cd readit-hub
   ```
3. Install the dependencies
   ```bash
   npm install
   ```
4. Start the development server
   ```bash
   npm start
   ```
5. Open http://localhost:3000 in your browser to view the app

## Tech Stack

- React
- JavaScript
- CSS
- Spotify Web API
